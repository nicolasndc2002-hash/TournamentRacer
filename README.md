# TournamentRacer
Simulador de Corridas no estilo do minimap do formula 1 com direito a modos: Casuais, Campeonatos, Time Trial, Ranqueado, Equipexequipe e Torneios. Tambem tem como vc criar Pilotos, Equipes e Fazer suas pistas usando sistema de SVG. Possui RANKS, Conquistas, Hall da fama e histórico de partidas com TUDO EDITÁVEL.
